---

## 📌 نبذة عن المشروع

يقوم **بوت قناة ريحانة المغرب الأوسط** بإدارة وتسهيل النشر على القناة عبر نظامين:

1. **نظام نشر المجلة (صباحاً ومساءً):**
   - استخراج صفحات المجلة (`PDF`) وتحويلها إلى صور عالية الجودة (`DPI 200`).
   - استخراج النص المرفق في الصفحة ونشره مع الصورة.
   - التتبع الآلي للصفحة الحالية لضمان استمرارية النشر دون تكرار.

2. **نظام النشر الدوري (كل 3 ساعات):**
   - نشر توجيهات ونصائح موجهة للموحدين والمناصرين لتكون درعاً حامياً للأمة الإسلامية.
   - ختم جميع المنشورات الدورية بالتذييل الإجباري كصدقة جارية.

---

## ✨ المميزات الرئيسية

- 📸 **استخراج الصور بدقة عالية:** تحويل صفحات الـ PDF إلى صور صافية.
- ⏰ **جدولة مزدوجة:** نشر المجلة مرتين يومياً (09:00 صباحاً و 08:00 مساءً) + منشور نصحي وتحفيزي كل 3 ساعات.
- 💬 **تذييل إجباري:** إضافة التذييل المخصص تلقائياً لكافة منشورات الـ 3 ساعات:
  > *"هذي القناة هي صدقه جارية للأخت الأندلسية أم عقيدة وحمزة غـفر الله لها وجعلها في ميزان حسناتها ☝🏻⚔️🖤"*
- ⚡ **أداء برمجي غير متزامن (Asyncio):** أداء عالٍ وبدون استهلاك مفرط للموارد لمنع توقف البوت.
