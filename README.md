---

## 📌 نبذة عن المشروع

يقوم **بوت قناة ريحانة المغرب الأوسط** بأتمتة عملية نشر المجلات الإلكترونية عبر الخطوات التالية:
1. قراءة ملف المجلة (`PDF`) واستخراج الصفحات صفحة تلو الأخرى.
2. تحويل كل صفحة إلى صورة عالية الجودة (`DPI 200`).
3. استخراج النص الموجود بالصفحة وإرساله إلى نموذج **Groq AI (Llama 3.3)** لإعادة صياغته وتنسيقه بأسلوب منشورات التليجرام الجذابة (عناوين، إيموجي، وهاشتاجات).
4. جدولة النشر التلقائي مرتين يومياً (منشور الصباح ومنشور المساء).
5. تتبع رقم الصفحة بشكل آلي لمنع التكرار وضمان الاستمرارية.

---

## ✨ المميزات الرئيسية

- 📸 **استخراج الصور بدقة عالية:** تحويل صفحات الـ PDF إلى صور صافية وجذابة.
- 🧠 **إعادة صياغة ذكية:** معالجة النصوص عبر ذكاء Groq الاصطناعي لإظهارها بشكل مهندم ومناسب للتليجرام.
- ⏰ **جدولة النشر التلقائي:** ضبط أوقات النشر صباحاً ومساءً عبر مكتبة `APScheduler`.
- 🔄 **نظام تتبع التقدم:** حفظ رقم آخر صفحة تم نشرها في ملف محلي.
- 🚀 **جاهز للاستضافة:** إعدادات مجهزة للرفع والعمل 24/7 على منصة **Railway**.
